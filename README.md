# Jobayer Hossain Rafi — Research website

A responsive, static academic website for GitHub Pages. Open index.html locally to preview. No installations, build tools, or paid services required.

## Publish
1. Sign into GitHub as jobayerrf-biotech.
2. Create a new PUBLIC repository named exactly jobayerrf-biotech.github.io. Enable Add README so the main branch exists.
3. Extract this ZIP on your computer.
4. In the new repository, choose Add file > Upload files.
5. Drag all HTML files, this README.md, and the assets folder FROM INSIDE the extracted folder into the upload box. Do not upload the ZIP or outer folder. The optional .nojekyll file can also be uploaded if visible.
6. Commit directly to main.
7. Go to Settings > Pages. Under Source choose Deploy from a branch; select main and /(root); click Save.
8. Wait for the GitHub Pages deployment to finish (it may take up to 10 minutes). Visit https://jobayerrf-biotech.github.io/.
9. Check every navigation item, research project, email link, and CV download. On a phone, confirm the navigation wraps and text stays readable.

The index.html file must be at the root, beside research.html, cv.html, publications.html, contact.html, and the assets folder. This is a different repository from jobayerrf-biotech/jobayerrf-biotech, which controls the GitHub profile README.

## Editing
Edit the HTML page you want to change. Styles are embedded in each page for portability. Upload and commit the changed file to refresh the website.

## Content
The project pages use the prepared research overview summaries. No raw research data, sample identifiers, unpublished result figures, or confidential protocols are included. The presentations page includes selected recognition supplied in the user's background; no journal articles or publication identifiers are invented. The CV is a selected summary, not a complete academic CV. Contact uses the professional outreach email provided in context. No analytics, tracking, or contact-form data collection is included.

Prepared October 2026. The package itself does not activate hosting; complete the GitHub Pages steps above.
